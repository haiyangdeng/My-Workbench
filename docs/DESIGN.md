# AI员工工作室设计规范

当前版本为0.4.0。用户选择AI工作室：员工分布在工作区，任务与交接发生在空间中。主界面采用动态工作区、上方项目桌和对齐卡片，日常操作从员工、任务、项目、工具架和素材盒展开。

## 空间与对象

默认影像、声音、开发、视觉四区，可继续添加与编辑。图标与主题色帮助辨认工作区；真实能力通过工具配置、任务状态和日志说明。空工作区直接显示招募入口，原生空状态使用真实计数。

| 对象 | 展示与操作 |
| --- | --- |
| 员工席位 | 姓名、头像、职位；点击查看档案、所属任务和配置 |
| 工作区成员 | 同区多人列表；每人独立配置职责与工具，新增不覆盖原员工 |
| 桌面任务 | 标题、负责人、状态；原地查看输入、run、日志、审核和产物 |
| 项目桌 | 选择或添加项目，摊开任务、交接和协作步骤，生成AI计划 |
| 工具架 | CLI、Codex、ComfyUI配置、停用、版本或连接检查、SSH隧道 |
| 素材盒 | 当前项目归档文件、来源run、验收状态、预览与Finder定位 |
| 项目协作 | 已批准步骤、依赖、进度、审核方式、暂停与停止 |

真实交接在项目详情中展示来源、接收方与记录。稳定工作区、员工、任务和run编号不随姓名、头像或配色变化。

## 视觉

| 元素 | 规范 |
| --- | --- |
| 底色与表面 | 暖白#F4F3EE，表面#FFFEFA，主色#58735E；深色使用墨绿底与可读文字 |
| 文字 | 主文字#282C29，次级#797D75；系统中文字体，标题28左右，正文12–13，日志等宽 |
| 工作区 | 影像陶土#B97255，声音灰紫#8D7D9A，开发灰蓝#658398，视觉鼠尾草#708A73；新增工作区可自选 |
| 层次 | 无倾斜卡片、14像素圆角、清晰边框、轻阴影；对象详情可滚动 |
| 状态 | 文字与颜色同时表达；执行成功为待验收，验收后才完成 |
| 配色 | 暖白浅色、墨绿深色；默认明确为浅色，原生保存选择，布局不改变业务数据 |

主窗口1440×900，最小1100×720。两列卡片根据高度收紧布局，超出视口时纵向滚动。原生对象详情为355或320宽，员工主要任务入口固定在底部；终端展开后可拖动分隔条调整高度。计划确认680高，步骤独立滚动，底部批准入口保持可见。

## 员工与头像

全局招募入口与工作区内招募均支持新增员工；工作区入口预选部门。成员列表展示同区所有员工。编辑复用稳定编号，保留历史执行快照。

头像可选择姓名首字、人物、灵感、开发或设计符号，也可上传本地图片。原生读取有效图片并生成最长边160像素缩略图，最大源文件10MB；缩略图随配置保存，移走原图仍可显示。选择预设移除当前图片。姓名、职位、部门、职责和绑定工具独立编辑。

原型表单用两列组织姓名、职位、部门和工具，头像与职责使用整行；小窗口仍能滚动至提交入口。原型档案是演示状态，刷新会重置。

## 任务、交接与协作

点击员工后创建草稿预选负责人；草稿拖到另一员工只提出分配建议，确认后修改负责人。键盘用户在详情中选择并确认同一动作。已经执行的任务不通过拖拽换人。

任务详情显示目录、工具、超时与可展开的逐项argv，避免长输入淹没操作按钮。每次执行可切换历史run；复制显示日志、打开完整归档、验收或填写返工说明。返工生成新run，旧结果保留。

独立草稿可确认移出，在对应项目桌的“已移出草稿”中恢复；恢复保留原编号和输入。已有执行、协作步骤和被依赖的任务保留在原处。日志及文本产物预览使用原生只读文本组件，支持选取和滚动。头像预设、个人档案、终端关闭和复制日志具有明确中文辅助功能标签；配置窗口支持Escape取消。

产物显示名称、大小、类型和验收状态。文本预览显示前100KB，图片通过缩略图预览，其他媒体打开系统应用。远程文件先显示服务位置与大小，主动下载后才可验收。

交接表单审阅来源run、接收员工、已验收文件、目标、参数、约束、检查、疑问和验收标准；确认后建立下游草稿。AI规划也先展示可编辑步骤、员工和依赖，确认后才执行；默认人工验收，可指定独立审核员工与0至2次返工上限。审核不足或失败时暂停，已完成步骤不重复。

## 原型和证据

design/studio-v03.html是评审原型，不运行工具或收费服务。旧prototype.html保留为历史方案。最新原生与原型截图：

- design/studio-overview.png、studio-team.png、studio-profile-config.png：空间原型及多员工配置。
- design/native-real-collaboration.png、native-collaboration-panel.png：实际AI协作记录的原生组件。
- design/native-profile-config.png、native-plan-approval.png、native-remote-config.png：最终配置界面。

原型键盘、弹窗焦点、搜索、拖拽确认、窗口边界由自动交互检查覆盖；原生构建、渲染、Store集成及人工尚需检查的范围见VALIDATION.md。原型行为不能替代原生或真实远程验收。

## 工作室V04实现

默认暖白浅色独立于系统模式，墨绿深色可手动选择并保存。首页不再倾斜或缩放，使用两列端正卡片，按窗口高度收紧布局，多工作区和多员工可纵向滚动。工作区使用稳定编号，登录检测和终端入口位于员工档案。新增要求见PRD_V04_ADDENDUM.md，参考图见design/review-v04，原生组件渲染见design/native-v04。
