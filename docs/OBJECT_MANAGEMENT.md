# Workbench 对象管理

2026-10-18，0.5.0 构建 7。

## 操作入口

| 对象 | 查看与修改 | 删除入口与影响 |
| --- | --- | --- |
| AI 员工 | 员工页搜索姓名、职位、职责；卡片“编辑”或档案“编辑员工档案” | 卡片或档案“删除”，从所有工作区及员工目录移除 |
| 工作区成员 | 员工页各分组“添加员工”支持新建或添加已有员工；工作区卡片及详情提供同类入口 | “移出工作区”仅移除当前成员关系；其他工作区及员工档案保留 |
| 工作区 | 首页卡片菜单、管理工作区、详情“编辑” | 卡片菜单或管理列表“删除”；保留员工与项目，移除此工作区关联 |
| CLI / 旧版远程工具 | 工具连接中新增、查看、编辑 | 各工具卡片“删除”；员工仍绑定该 CLI 时需先换绑或删除员工 |
| 制作服务器 / 工作流模板 | 工具连接中新增、查看、编辑 | 各卡片“删除”；保留执行记录与已下载文件 |
| 项目 | 全部项目中筛选、打开、编辑 | 项目菜单或详情“删除项目”；相关对话、任务、计划、产物同步退出当前列表 |
| 项目分类 | 全部项目的“管理分类”中新增、编辑、排序 | 删除分类后，项目移到“未分类”；内置“未分类”不可删除 |
| 对话 | 项目对话列表查看、重命名 | 列表“删除”或对话菜单；保留历史消息，已转为任务的工作保留 |
| 普通任务 | 新建任务；详情“编辑任务”修改标题、输入、标准、目录、负责人、项目、权限 | 详情“删除任务”；计划步骤应从计划整体删除 |
| 协作 / 制作计划 | 批准前编辑步骤；创建后可在工作流中重命名、暂停、停止 | 工作流“删除计划”；同时移除计划步骤，保留执行历史 |
| 产物 | 产物列表筛选、预览、“重命名” | 每项“删除”；移除列表条目，保留归档文件与来源记录 |

同一位员工加入多个工作区时，共用档案。编辑姓名、职责或 CLI 会作用于各处。移出主工作区后，其他归属自动成为主工作区；移出最后一个工作区后，在员工页的“未分配工作区”继续查看、编辑、删除或重新分配。

## 执行与历史

修改普通任务的输入、验收标准、负责人、项目、目录或权限后，任务回到草稿，等待再次执行；仅改标题保留状态。任务编号、创建时间、旧执行及其员工、CLI、输入和验收标准快照不变。详情可选择历史执行；草稿的当前修改稿不会显示为已经执行。运行中、排队中以及计划生成的步骤不提供普通任务编辑入口。

删除需要确认。存在运行或排队任务、未确认远程执行状态、活动终端、待合并或冲突的 worktree、未完成下游依赖时，会阻止相关删除并显示处理原因。停止任务、处理依赖或更换绑定后可重试。

删除使用持久化删除标记。对象退出日常列表和选择器，重启、迁移或扫描产物不会恢复它；历史执行快照、原始消息、归档和用户目录中的文件保留。当前版本没有回收站或恢复入口，不提供自动清理磁盘文件、删除 CLI 登录或关闭云服务器功能。

## 可重复验证

```sh
zsh scripts/verify_crud.sh
```

该脚本使用独立 SQLite 数据库和本地 `printf`，检查真实 Store 的创建、编辑、成员关系、运行中保护、删除、历史保留和重启结果，输出 `work/crud-qa/crud-verification.json` 与原生界面离屏截图。核心关联保护用例在 `Tests/WorkbenchCoreTests/ObjectManagementTests.swift`。这些检查不会访问日常工作数据库或调用付费模型，也不替代真实点击、键盘、VoiceOver 与远程业务验收。
