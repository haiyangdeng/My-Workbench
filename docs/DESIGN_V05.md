# 工作室界面设计与交互 V05

日期：2026年10月6日。版本：0.5.0，构建6。状态：按用户参考图实现，构建、自动测试及原生组件渲染验证通过。

本版以用户提供的[界面参考图](design/studio-v05/reference.png)为视觉依据，使用SwiftUI实现原生工作台。首页突出工作区、员工与任务，侧栏承载项目、工具和配置入口。新布局接入现有本机SQLite、CLI执行与终端，保留工作区多人配置和任务验收流程。

## 布局与视觉

窗口左侧为固定导航，主区域顶部使用浅蓝AI球体视觉横幅。左侧标题为“我的 AI 工作室”和“Make room for ideas.”，右上角放置搜索、待验收提醒与设置入口。底部固定想法输入栏；打开终端时，底部区域显示终端与任务日志。

默认四个工作区按两列排列，保持端正、统一圆角和对齐间距。卡片左侧显示标题、用途与插画，右侧显示员工头像、真实任务状态和创建入口。

| 工作区 | 插画 | 主题色 |
| --- | --- | --- |
| 影像工作区 | 摄影机与玻璃展台 | 橙色 |
| 声音工作区 | 麦克风与波形 | 紫色 |
| 开发工作区 | 笔记本电脑与代码面板 | 蓝色 |
| 视觉工作区 | 调色盘与画笔 | 绿色 |

插画为独立图片资源，标题、员工、任务和操作按钮由原生界面绘制。资源及生成提示保存在[视觉素材目录](design/studio-v05/)。默认配色为“云蓝 · 浅色”，不随系统深色自动改变；用户可在设置中选择“夜幕 · 深色”。

## 导航与内容

| 导航 | 内容与操作 |
| --- | --- |
| 我的工作室 | 所有项目的工作区汇总，查看成员、任务，添加和编辑工作区 |
| AI 员工 | 按工作区展示员工，添加员工、配置头像和职责、检测登录、打开终端 |
| 项目任务 | 选择或添加项目，创建任务、查看执行与验收、恢复已移出的独立草稿 |
| 工具连接 | 注册和编辑CLI或ComfyUI，检测版本/连接，配置登录命令和SSH隧道 |
| 素材库 | 查看当前项目归档产物，预览、打开Finder并追溯执行 |
| 知识库 | 聚合当前项目目标、工作室员工职责、当前项目已验收任务 |
| 工作流 | 查看当前项目协作计划、依赖步骤和员工交接，生成计划、暂停或停止后续执行 |
| 设置 | 选择配色、调整同时执行任务数、管理工作区 |

知识库复用已有记录，点击来源员工或任务查看详细内容。它不增加RAG检索、知识自动注入或服务器存储。工作流页复用已有协作计划与交接数据，ComfyUI工作流配置仍从“工具连接”进入。

搜索支持项目、员工与任务，快捷键为⌘K。铃铛以真实待验收任务显示提示。员工、工作区和任务详情在当前页面右侧展开，关闭按钮或Escape收起；切换侧栏页面关闭详情。

## 想法输入与创建任务

在底部输入想法后，发送按钮或回车打开新任务表单，把内容预填到任务输入，并从首行生成可编辑标题。用户仍需检查负责人、归属项目、工作目录和验收标准。保存创建草稿，执行由用户从任务详情发起。

取消表单会保留输入栏中的原始想法，保存成功才清空对应内容，并展开新任务详情。尚无启用员工时，界面引导用户接入工具或添加员工，同时保留输入。附件按钮将用户选择的本机文件路径加入任务输入，不上传文件，也不把路径选择当成任务已执行。

## 动态工作区与真实状态

默认四区以稳定编号与员工关联，新增工作区追加到首页，可滚动查看。侧栏“管理工作区”、首页底部“添加工作区”和设置页提供相应入口。每区可配置多位员工，名称、用途、图标和主题色可编辑。改名不修改员工编号、任务关系、工作目录或历史执行快照。

默认四区使用各自插画；新增工作区使用所选图标与主题色。头像仍可选择预设或上传本地图片，保存后不依赖原图片路径。

卡片显示实际员工数量和任务状态，包括草稿、排队、执行、待验收等。当前任务模型没有连续百分比，界面不复制参考图的示例进度数字。员工是否已登录以工具状态检测结果为准，未经检测不显示为在线。首页汇总所有项目；项目任务、素材库和工作流按当前项目筛选。

## 数据与执行

员工、工作区、项目、任务、执行、产物索引、交接与计划继续存储在本机`~/Library/Application Support/MyWorkbench/workspace.sqlite`，日志和文件位于同目录的`Archives`。界面改版不新增服务器数据库或同步服务。

CLI使用既有账号和权限，登录检测与手动终端保持独立；ComfyUI按已有连接配置运行。终端收起保留会话，结束会话关闭对应进程；管理任务继续保存独立执行记录、完整日志与验收结果。源码中的长日志原生文本组件继续使用。
