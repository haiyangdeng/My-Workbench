# 个人AI管理工作站界面与终端需求补充

2026年10月2日，用户确认工作室V04设计，并授权以实际好用为目标调整细节。本补充适用于0.4.0，覆盖基础PRD中固定四区画布、跟随系统配色以及暂不包含PTY终端的旧约定。Word版v0.3继续作为M0至M4基础需求，阅读时需结合本补充。

## 首页与配色

首页采用对齐、无倾斜的工作区卡片和上方项目桌。员工、任务与协作仍就地展开，底部提供工具、招募、素材和终端入口，保留⌘K搜索。项目进度来自当前项目的真实任务验收状态。默认明确使用暖白浅色主题，独立于系统深色模式；可选择墨绿深色并保存偏好。

1440×900与1100×720采用两列布局。根据窗口高度收紧卡片间距和头像尺寸；超过默认四区后纵向滚动。成员数量不受固定席位限制，每位员工单独配置头像、职责和工具。

## 可配置工作区

工作区包含稳定编号、名称、图标、六位主题色、用途和顺序。默认初始化影像、声音、开发、视觉四区，支持新增和编辑。名称需唯一且不超过40字。工作区通过编号关联员工；改名同步当前员工的展示名称，历史执行快照保持当时的信息。

旧部门数据迁移时保留员工、工具、任务、执行编号。四个已知部门映射到默认工作区，其他部门保留为独立工作区。SQLite升级前用数据库备份接口创建workspace.pre-v04.sqlite，迁移和保存使用事务。数据损坏或版本不支持时不覆盖记录。

## 登录状态与终端

登录检测属于工具配置，多位员工共享同一CLI配置时共享检测结果。状态区分待检测、检测中、已登录、未登录、检测失败和未配置检测。Codex使用login status，明确的Not logged in诊断才归为未登录；超时或其他失败保持检测失败。其他CLI可配置检测argv，退出码0表示已登录。检测不提交任务、不产生run、不调用模型。

按需打开真实PTY终端，显示员工、工具和初始目录；可启动CLI、登录和手动输入命令。终端由SwiftTerm 1.10.0的AppKit组件承载，支持ANSI、Unicode、调整行列、选择、复制与粘贴。登录命令由CLI负责认证，工作台不复制CLI凭证。

关闭面板保留当前会话；结束会话、中断前台命令和停止管理任务使用各自入口。手动终端操作不自动获得任务完成或验收状态。程序退出前显示仍在运行的任务与终端数量。只保存最近12个会话的员工、工具、名称和初始目录；重启不启动旧进程、不恢复命令内容，选择历史项会新开会话。终端中的实际键盘、输入法与辅助功能仍需人工检查。

## 数据边界

本产品默认在单台Mac本地运行，无服务器数据库依赖。SQLite保存工作区、工具、员工、项目、任务、run、产物引用、交接、计划和审核。Archives保存日志和文件，terminal-history.json只保存会话元信息。远程API凭证通过macOS钥匙串保存，CLI登录凭证由CLI自身管理。仅在配置远程工具、SSH或ComfyUI时连接指定服务，多设备同步不在本轮范围。

## 图标

应用图标使用暖白陶瓷底板和鼠尾草绿W形工作室，四个不同配色工位代表默认工作区。生成与导出资源保留透明背景，提供macOS全部10个图标尺寸。
