02 / FROM IDEA TO DONEYOU'RE IN CHARGE

A small team.
A good way to work.

Bring Codex, Claude Code, or another command-line agent. Give each a job. Then turn the back-and-forth into a process you can actually see.

  1. 01

    Tell the team

    Start with an idea, a brief, or a file. Every project keeps its own conversations.

  2. 02

    Shape the plan

    A lead agent proposes the steps. Edit the plan and approve it when you're ready.

  3. 03

    Let it happen

    Follow the work as it streams in. Queue, stop, retry, or jump into a terminal.

  4. 04

    Make the call

    Check the files and diffs. Accept what works. Send the rest back for another pass.

YOUR TEAM, ON THE SAME PAGE

More than a chat window.

Roles, permissions, dependencies, and a shared goal. Workbench gives each AI employee a place in the process — while you keep the final say.

  • Read-only and Edit access, chosen by you
  • One writer per folder, with optional Git worktrees
  • Each agent continues its own CLI session
