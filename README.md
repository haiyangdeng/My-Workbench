# My Workbench

macOS原生个人AI管理工作站，以可配置工作区和项目组织员工、任务、产物及协作。0.5.0（构建6）按2026年10月6日确认的参考图实现侧导航、浅蓝视觉横幅、四色插画工作区和底部想法输入栏。本轮46项自动测试、Debug与Universal Release构建、原生多尺寸组件渲染检查通过。当前工程覆盖本地执行、远程接入接口与M4协作功能；可交付范围以验证记录为准。

## 本机启动

用Xcode打开MyWorkbench.xcodeproj，选择MyWorkbench scheme运行。构建也可以执行：

```bash
zsh scripts/build.sh
```

应用位于.build/xcode/Build/Products/Debug/MyWorkbench.app。脚本识别本机已有Xcode 26.2，也支持DEVELOPER_DIR指定其他安装。核心不需要额外数据库服务或本地模型。

默认使用“云蓝 · 浅色”，系统深色时也保持浅色；侧栏“设置”或右上角个人头像可选择“夜幕 · 深色”。侧栏“管理工作区”和首页底部“添加工作区”支持配置名称、图标、主题色和用途。

第一次可在侧栏“工具连接”选择“体验本地验证”，执行真实printf命令后人工验收；该入口在尚未配置工具时显示。“工具连接”注册本地CLI或ComfyUI服务；一个工作区可以招募多位员工，档案中配置姓名、头像、职位、职责和工具。首页卡片与“AI 员工”目录均可打开员工详情，任务详情在当前页面右侧展开。

底部输入栏会把想法预填到新任务表单，取消后保留原输入；补充负责人、项目目录和验收标准，保存后仍需主动执行。附件按钮把所选文件路径加入输入。卡片显示实际任务状态与员工数量，不用示例百分比或未经检测的在线状态。

“项目任务”管理项目、任务和草稿；“素材库”查看当前项目归档产物；“工作流”查看计划与员工交接。“知识库”聚合现有项目目标、员工职责和已验收任务，来源内容可查看，未新增RAG检索或自动知识注入。

本地任务支持有限并发、排队、超时、停止所属进程组、完整日志与独立run、产物导入、预览和返工。验收后可确认交接，生成下游草稿。“项目任务”添加项目后，已绑定Codex的员工可以生成协作计划；审阅步骤与依赖后启动，可选择人工或AI审核和有限返工。

独立草稿可确认移出并在“项目任务”恢复，原编号与输入保留。0.3.1修复长日志布局卡顿，历史检查记录见验证文档；0.5.0的原生渲染、交互和构建结果以本轮最终验证为准。

## 工具接入

通用CLI使用绝对路径、非交互模式和每行一项的argv。{input}替换完整输入，{output}表示本次产物目录；也通过MYWORKBENCH_OUTPUT_DIR传入目录。工作目录不是操作系统沙箱。AI CLI保留自身权限控制。

Codex使用已安装CLI的exec模式与现有登录，默认只读；选择允许写入后才启用workspace-write。规划和审核使用结构化JSON和只读模式，结果自动归档。

ComfyUI选择API格式工作流与服务URL，可通过已配置SSH别名建立回环隧道。需要按编号取消任务的job接口。API凭证只保存于钥匙串。预算说明仅用于核对，实际费用上限由服务设置。下载与远程业务验收需使用实际指定服务完成。

## 数据和交付

数据位于~/Library/Application Support/MyWorkbench/workspace.sqlite，日志与产物保存在同目录的Archives。升级会保留旧JSON及备份。更改员工不修改历史执行快照；返工保存新版本。

本机应用使用ad hoc签名。Developer ID、公证与App Store分发未包含在本次范围。远程实际生成、原生人工操作及不同硬件运行的验证状态见VALIDATION.md；不能以构建成功代替业务验收。

执行zsh scripts/package_release.sh生成Universal Release应用包、源码包与SHA-256校验文件，输出位于releases。0.5.0交付包包含当前PRD、设计、使用说明与验收记录。

0.4.0新增的CLI登录检测与按需内置终端在本版保留，可从员工档案或侧栏“终端”打开。收起面板保留会话，结束会话才关闭进程；重启仅恢复最近会话的员工、工具与初始目录。手动命令和管理任务分别记录状态。首次构建由SwiftPM下载固定版本的终端依赖。Word v0.3基础PRD需结合V04需求补充与V05界面文档阅读。
